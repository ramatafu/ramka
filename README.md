# ramka — Stage 1 (локальный зашифрованный чат по LAN)

## О проекте

`ramka` — приватный P2P-мессенджер для Android. Идея: два человека в одной
локальной сети должны иметь возможность переписываться, не проходя ни через
какой сервер вообще, с шифрованием, которое проверяемо аутентифицирует
собеседника (а не просто "шифрует трафик до кого-то"). Единственный источник
истины по функциональности и ограничениям — `PROJECT_SPEC.md` в корне репозитория;
этот README описывает конкретно то, что реализовано на Stage 1, и как это
проверить руками.

# Ramka

**Приватный P2P-мессенджер для доверенного круга.**

Ramka — мобильный мессенджер для тех, кто ценит приватность выше функциональности. Никакого облака, никаких метаданных, никаких социальных функций — только зашифрованное общение между людьми, которым ты доверяешь.

## Философия

- **Минимализм**: Только то, что нужно для безопасной связи.
- **Приватность**: Нет статусов прочтения, онлайн-статусов, утечек метаданных.
- **Свой сервер**: Ты контролируешь инфраструктуру. Никаких сторонних серверов.
- **Без лишнего**: Никакого ИИ, историй, ботов, "умных" функций.

## Возможности

### Основное
- Сквозное шифрование (протокол Noise IK)
- Голосовые и видеозвонки (WebRTC)
- Отправка файлов и голосовых сообщений
- Добавление контактов через QR-коды (одноразовые приглашения)
- Обнаружение в локальной сети (mDNS)

### Устойчивость сети
- **Прямое P2P**: Работает по локальному Wi-Fi без сервера
- **Релей-серверы**: Собственный релей для связи вне локальной сети
- **Прокси**: Поддержка SOCKS5/HTTP для скрытия IP от релея (Xray/Reality)
- **Yggdrasil**: Опциональная поддержка mesh-сети для обхода блокировок
- **Yggmail**: Резервный канал через собственную почту (SMTP/IMAP)

### Безопасность
- SQLCipher для шифрования базы данных
- Android Keystore для чувствительных данных
- Certificate pinning для релей-соединений
- Fail-closed логика прокси (без утечки IP)
- Имена файлов хранятся как хэши (без метаданных)

## Чего нет в Ramka (намеренно)

- Нет статусов прочтения
- Нет индикаторов "печатает"
- Нет статусов онлайн/оффлайн
- Нет облачных бэкапов
- Нет регистрации по номеру телефона
- Нет социальных функций (истории, каналы, боты)
- Нет интеграции с ИИ

## Технологии

- **Язык**: Kotlin
- **UI**: Jetpack Compose
- **DI**: Hilt
- **База данных**: Room + SQLCipher
- **Шифрование**: Noise IK (libsignal-protocol)
- **Звонки**: WebRTC (stream-webrtc-android)
- **Сеть**: Собственный стек P2P/релей/прокси

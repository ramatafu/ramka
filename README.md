# Ramka

**Ramka** — это децентрализованный мессенджер с акцентом на приватность, работу в локальных сетях (LAN) и возможность использования self-hosted relay-серверов для доставки сообщений через интернет.

## 🚀 Ключевые особенности

- **Приоритет LAN:** Обнаружение собеседников и обмен сообщениями через mDNS в локальной сети без участия внешних серверов.
- **Пул Relay-серверов:** Поддержка до 5 резервных relay-серверов для гарантированной доставки сообщений, если прямое соединение невозможно.
- **Сквозное шифрование:** Relay-сервер видит только зашифрованные байты и не может прочитать содержимое сообщений.
- **Гибкая фоновая работа:** Настраиваемые режимы фоновой доставки (WorkManager или Foreground Service) для обхода агрессивных ограничений Android.

## 🏗 Архитектура

Проект следует принципам Clean Architecture и разделён на модули:
- `:domain` — бизнес-логика, модели данных, интерфейсы хранилищ и контроллеры (например, `RelayPoolController`, `RelayHealthMonitor`).
- `:app` — слой представления (Jetpack Compose), ViewModel, внедрение зависимостей (Hilt) и адаптеры.
- `:network` — работа с сетью, mDNS обнаружение и криптография.
- `:data` / `:storage` — работа с `DataStore` и безопасное хранение токенов.

## ⚙️ Настройка Relay-сервера

Для работы через интернет обоим собеседникам необходимо настроить одинаковый пул релеёв.

1. Перейдите в **Настройки → Релеи**.
2. Нажмите **«Добавить релей»**.
3. Заполните поля:
   - **Адрес:** `host:port` (например, `relay.example.com:48766` или `192.168.1.10:48766`). Без `http://` или путей.
   - **Токен доступа:** Секретная строка (16–64 байта), настроенная на вашем сервере.
   - **Пин сертификата:** 64 hex-символа SHA-256 отпечатка сертификата сервера. *Обязательно для IP-адресов, опционально для доменов с доверенным SSL (Let's Encrypt).*
4. Нажмите **«Проверить»**, чтобы убедиться в корректности настроек. Статус изменится на ✅ OK.
5. Нажмите **«Сохранить»**.

### Экспорт и Импорт настроек
Чтобы не вводить данные вручную на нескольких устройствах:
1. На настроенном устройстве нажмите **«📋 Экспорт»**. Данные пула будут скопированы в буфер обмена в виде JSON.
2. На новом устройстве нажмите **«📥 Импорт»**, вставьте скопированный текст и подтвердите. *Внимание: это заменит текущий список релеёв.*

## 🛠 Сборка и запуск

Для сборки проекта требуется JDK 17+ и Android SDK.

```bash
# Клонирование репозитория
git clone https://github.com/ramatafu/ramka.git
cd ramka

# Сборка отладочной версии APK
./gradlew assembleDebug

# Запуск всех тестов
./gradlew test
